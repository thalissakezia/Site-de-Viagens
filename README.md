# PegaAvião - Site de Viagens

Site de uma agência de viagens fictícia, feito em 2022 enquanto eu estudava HTML, CSS e Bootstrap.

Páginas:

- Início
- Destinos
- Promoções, com cards de pacotes e preços
- Contato, com formulário e endereço

## Tecnologias

- HTML5
- CSS3
- Bootstrap 5
- Material Design Icons

## Como ver

Baixe o repositório e abra o `index.html` no navegador. Também dá para publicar direto pelo GitHub Pages.
